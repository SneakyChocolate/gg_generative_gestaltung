# Aufgabe

Programmieren Sie ein aufregendes Feuerwerk auf Basis von Partikelsystemen. Den Code aus CC 27 können Sie gerne als Basis dazu verwenden. Erweitern Sie den Sketch um Ihre eigenen interessanten Feuerwerkskörper. Haben Ihre Raketen Klänge? Vielleicht hinterlassen sie glitzernde Spuren oder malen Herzen oder Text in die Luft? Vielleicht explodieren Ihre Partikel ein weiteres Mal? Auch eine Verbesserung hinsichtlich von Abschusswinkel, 2D / 3D Darstellung, Variationen in Geschwindigkeit, Höhe, Farbe, Größe, etc. bieten sich an.

Reichen Sie Ihre Abgabe als zip Datei über Moodle ein.

## Hinweise

Es muss eine klare, eigene Leistung in der Abgabe erkennbar sein. Alle verwendeten Quellen müssen im Quelltext genannt werden.
Optimieren Sie Ihren Code im Hinblick auf die Geschwindigkeit - versuchen Sie eine ausgewogenes Verhältnis zwischen der Anzahl der Partikel und dem Aufwand der visuellen Darstellung der Partikel zu finden.
Stellen Sie sicher, dass Ihr Sketch im Vollbildmodus auf verschiedenen Auflösungen ein schönes Ergebnis liefert.

## Bewertung

Die Bewertung erfolgt mit 0 bis 5 Punkten. 1 Punkt gibt es jeweils für:

Die Abgabe einer funktionsfähigen Lösung
Die Verwendung von Partikelsystemen
Ein aufregendes Feuerwerk
Die Verfolgung eines eigenständigen, gestalterischen Idee
Technische oder gestalterische Exzellenz
